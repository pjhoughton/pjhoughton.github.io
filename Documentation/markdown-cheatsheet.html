Glossary

TermExplanation
HeadingTitles created with # symbols. More # = smaller heading.
BoldText wrapped in ** for emphasis.
ItalicText wrapped in * for lighter emphasis.
Inline CodeShort snippets wrapped in backticks `like this`.
Fenced Code BlockMulti‑line code wrapped in triple backticks ```.
BlockquoteQuoted text starting with >.
ListBulleted with - or numbered with 1..
LinkClickable text using [title](url).
ImageEmbedded picture using ![alt](path).
TableRows and columns defined with | and -.
