📚 Reading Room

Reading Room contains a curated collection of eBooks covering Automation, Ansible, DevOps, Kubernetes, Linux, PowerShell, Python, Terraform and Zabbix

The Reading Room contains a curated collection of books and learning resources covering Automation, Ansible, DevOps, Kubernetes, Linux, PowerShell, Python, Terraform and Zabbix. These resources support continuous learning and provide practical guidance for developing skills used throughout this website and associated GitLab repositories.

📖 Ansible

Ansible for DevOps

A practical guide to using Ansible for configuration management, server provisioning, application deployment, and infrastructure automation. The book focuses on repeatable and maintainable automation techniques suitable for both small and large environments.

  • Ansible for DevOps

    • Ansible: Up and Running (3rd Edition)

    A comprehensive reference covering modern Ansible development, including inventories, playbooks, roles, collections, templates, testing, and enterprise automation. Suitable for both administrators new to Ansible and experienced engineers building large-scale automation frameworks.

  • Ansible: Up and Running

    • The Tao of Ansible

    A concise introduction to the philosophy behind Ansible. The book focuses on building automation that is simple, readable, and maintainable while following best practices and avoiding unnecessary complexity.

  • The Tao of Ansible

    • 📖 DevOps

    The DevOps Engineer’s Career Guide

    A practical career roadmap for aspiring DevOps professionals, covering the skills, tools, and mindset needed to break into DevOps and cloud engineering roles. It includes advice on certifications, building experience, networking, and navigating the job market.

  • The DevOps Engineer’s Career Guide

    • The DevOps Handbook

    Considered one of the foundational DevOps books, it explains how organisations can improve speed, reliability, and security by adopting DevOps principles. It provides real-world practices for continuous delivery, automation, monitoring, and cultural transformation.

  • The DevOps Handbook

    • The Phoenix Project

    A business novel that follows an IT manager tasked with rescuing a failing project and struggling organisation. Through its story, it introduces the core concepts of DevOps, bottleneck management, workflow optimisation, and collaboration between IT and business teams.

  • The Phoenix Project

    • The Pragmatic Programmer (20th Anniversary Edition)

    A classic software engineering book focused on developing a professional mindset and effective coding habits. It teaches practical principles for problem-solving, learning, communication, code quality, and long-term career growth.

  • The Pragmatic Programmer (20th Anniversary Edition)

    • The Unicorn Project

    A companion novel to The Phoenix Project, told from a software developer's perspective. It explores modern software development, engineering culture, technical debt, data-driven organisations, and the challenges of digital transformation.

  • The Unicorn Project

    • Think Like a Programmer

    An introduction to analytical thinking and problem-solving through programming. Rather than focusing on a specific language, it teaches techniques for breaking down complex problems into manageable solutions and developing a programmer's mindset.

  • Think Like a Programmer

    • ☸️ Kubernetes

    Kubernetes – An Enterprise Guide (Third Edition)

    Focuses on deploying and managing Kubernetes in enterprise environments, covering security, GitOps, CI/CD, observability, service meshes, and scalable production workloads.

  • Kubernetes – An Enterprise Guide (Third Edition)

    • 🌍 Terraform

    Mastering Terraform

    Is an advanced guide to Infrastructure as Code, teaching how to automate and manage cloud infrastructure across AWS, Azure, and GCP with Terraform, Kubernetes, CI/CD pipelines, and GitOps practices

  • Mastering Terraform

    • ⚡ PowerShell

    Learn Windows PowerShell 3 in a Month of Lunches

    Is an advanced guide to Infrastructure as Code, teaching how to automate and manage cloud infrastructure across AWS, Azure, and GCP with Terraform, Kubernetes, CI/CD pipelines, and GitOps practices

  • Mastering Terraform

    • 🐍 Python

    Introduction to Python

    An accessible introduction to Python programming covering variables, loops, functions, modules, data structures, and scripting fundamentals. Ideal for readers beginning their programming or automation journey.

  • Introduction To Python

    • Cracking Codes with Python

    Teaches Python through cryptography and code-breaking projects. Readers learn programming fundamentals while building practical tools for encryption, decryption, and data analysis in a fun and engaging way.

  • Cracking Codes with Python

    • Real World Python

    Focuses on practical problem solving using Python. Topics include automation, data processing, utility development, and scripting techniques that can be directly applied to everyday IT and infrastructure tasks.

  • Real World Python

    • 📊 Monitoring & Observability

    The Zabbix Book

    A free, community-driven online guide written by Zabbix users for Zabbix users. It provides practical guidance on monitoring, alerting and platform management.
