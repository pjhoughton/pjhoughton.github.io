🐳 Docker Cheatsheet

Quick reference for Docker commands and container management

A quick reference guide covering essential Docker and Docker Compose commands, along with common maintenance tasks and terminology.

Essential Docker Commands

DescriptionCommand
Check Docker versiondocker --version
List running containersdocker ps
List all containersdocker ps -a
List imagesdocker images
Run a containerdocker run image_name
Run in backgrounddocker run -d image_name
Run with port mappingdocker run -p 8080:80 image_name
Stop containerdocker stop container_id
Remove containerdocker rm container_id
Remove imagedocker rmi image_id
Restart all docker compose containers using docker commands docker restart $(docker compose ps -q)

Docker Compose Commands

DescriptionCommand
Check versiondocker compose version
Start servicesdocker compose up
Start in backgrounddocker compose up -d
Stop servicesdocker compose down
View logsdocker compose logs
Exec into containerdocker compose exec service_name bash
Build servicesdocker compose build
List servicesdocker compose ps
Clean environmentdocker compose down --volumes --remove-orphans

Maintenance

DescriptionCommand
Remove stopped containersdocker container prune
Remove unused imagesdocker image prune
Remove unused volumesdocker volume prune
Remove unused networksdocker network prune
Remove everything unuseddocker system prune

Glossary

TermExplanation
ImageStandalone package with everything needed to run software
ContainerRunning instance of an image
DockerfileInstructions to build an image
VolumePersistent storage
NetworkContainer communication layer
RegistryStorage for images (e.g. Docker Hub)
TagVersion label for images
ComposeMulti-container orchestration tool
ServiceContainer definition in Compose
PruneCleanup unused resources
OrphanUnused leftover container
