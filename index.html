🏠 Welcome to My Website

This website serves as a central hub for all of my GitHub repositories. Each section highlights a different project, explains the ideas behind it, and shares the lessons learned along the way. Whether it's experimenting with homelab setups, automating tasks with Ansible, containerizing applications with Docker, or exploring smart home solutions, the goal is to document the journey and make it easier for others to follow along, learn, and contribute.

This website documents my homelab journey, automation projects and technical learning. Each section contains documentation, reference material and real-world examples collected from projects I actively use and maintain.
